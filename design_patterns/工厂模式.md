工厂模式（Factory Pattern）是一种创建型设计模式，用于创建对象的实例。它通过定义一个创建对象的接口，让子类决定实例化哪一个类。工厂模式将类的实例化延迟到子类。

### 工厂模式的特点
- 创建对象：工厂模式的主要目的是创建对象实例。
- 解耦：工厂模式将对象的创建过程与使用过程解耦，客户端代码不需要知道具体的实现类，只需要知道工厂接口。
- 可扩展性：通过工厂模式，可以轻松地增加新的产品类，而不需要修改客户端代码。

### 示例
```
type Constructor func(lazyjson.JSON) (Buffer,error)

var Buffers = map[consts.BufferType]Constructor{}

func Register(bufferType consts.BufferType,constructor Constructor){
    Buffers[bufferType] = constructor
}

func NewBuffer(typ consts.BufferType,j lazyjson.JSON) (Buffer,error){
    if f,ok := Buffers[typ]; ok{
        return f(j);
    } 
    return nil,errors.Wrap(errno.ErrorBufferTypeNotSupport,fmt.Sprintf("type: %s",typ))
}
```
在这个示例中，Register函数注册构造函数，通过NewBuffer函数创建Buffer实例。
