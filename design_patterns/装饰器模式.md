下面代码使用了装饰器模式（Decorator Pattern）。装饰器模式是一种结构型设计模式，它允许向现有对象添加新的功能，同时不改变其结构。装饰器模式通过创建一个包装对象，也称为装饰器，来包裹原始对象，从而提供额外的功能。
```
// wrapTransport is a simple warpper of the provided transport to add more headers into the http request.
type wrapTransport struct {
	http.RoundTripper
	headers map[string]string
}

// RoundTrip .
func (p *wrapTransport) RoundTrip(req *http.Request) (*http.Response, error) {
	if len(p.headers) != 0 {
		for k, v := range p.headers {
			req.Header.Set(k, v)
		}
	}
	return p.RoundTripper.RoundTrip(req)
}
```
装饰器模式的核心在于将现有对象包装在一个新的对象中，从而在不修改原始对象的情况下扩展其功能。

添加装饰器后，直接使用装饰器即可扩展资源：
```
tr := &http.Transport{}

// 原来
Transport: tr,

// 装饰器
Transport: &wrapTansport{
    headers: xx,
    RoundTripper: tr,
}
```

其中http.Transport{}和wrapTansport都实现了RoundTripper接口，符合Transport字段类型。
