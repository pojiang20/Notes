## 反射
运行时反射是程序在运行期间检查其自身结构的一种方式。反射带来的灵活性是一把双刃剑，反射作为一种元编程方式可以减少重复代码2，但是过量的使用反射会使我们的程序逻辑变得难以理解并且运行缓慢。[参考](https://draveness.me/golang/docs/part2-foundation/ch04-basic/golang-reflect/#43-%E5%8F%8D%E5%B0%84)

```
func Add(a, b int) int {
	return a + b
}

func TestT(t1 *testing.T) {
	// 获取函数
	v := reflect.ValueOf(Add)
	if v.Kind() != reflect.Func {
		return
	}

	// 构建入参
	input := []int{1, 2}
	t := v.Type()
	argv := make([]reflect.Value, t.NumIn())
	for i := range argv {
		if t.In(i).Kind() != reflect.Int {
			return
		}
		argv[i] = reflect.ValueOf(input[i])
	}

	// 调用
	result := v.Call(argv)

	// 处理返回值
	if len(result) != 1 || result[0].Kind() != reflect.Int {
		return
	}
	fmt.Println(result[0].Int())

}
```

## 泛型
泛型是一种编译时的类型检查机制。它在声明阶段确定类型，并在编译时就能检查这些类型。

```
type Box[T any] struct{
	items []T
}

func (b *Box[T]) Add(item T) {
	b.items = append(b.items,item)
}

func (b *Box[T]) GetAll() []T{
	return b.items
}

func TestT(t *testing.T){
	box := Box[string]{}
	box.Add("s1")
	box.Add("s2")
	fmt.Println(box.GetAll())

	numberBox := Box[int]{}
	numberBox.Add(1)
	numberBox.Add(2)
	fmt.Println(numberBox.GetAll())
}
```
